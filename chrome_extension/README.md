# 수원영통 네이버 예약 Chrome 확장 설치

이 확장은 수원영통 네이버 예약을 1분마다 확인해 로컬 운영본으로 전송합니다.

## 설치 전 설정

1. `local-config.example.js`를 복사해 `local-config.js`로 이름을 바꿉니다.
2. `agentToken`에 `D:\JumpingBattle_SuwonYT\.env`의 `NAVER_AGENT_TOKEN`과 동일한 값을 넣습니다.
3. `businessId`는 수원영통 값 `1376430`으로 이미 설정돼 있습니다.
4. 로컬 운영본이 `http://127.0.0.1:8081`에서 실행 중인지 확인합니다.

`local-config.js`는 GitHub에 올리지 않습니다.

## Chrome 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `chrome_extension` 폴더를 선택합니다.
5. 수원영통 네이버 예약 파트너 페이지에 로그인한 상태에서, 확장 아이콘을 눌러 즉시 동기화합니다.

## 현재 범위

현재는 예약 수집·상세값 전송·당일취소 집계만 활성화합니다. 네이버 예약 막기는 별도 서버 명령·상품 시간 설정을 확인한 후 추가합니다.
